Urdu Emotion AI is a Final Year Project that uses artificial intelligence and deep learning to recognize emotions from spoken Urdu. The system processes speech input, extracts relevant audio features, and predicts the speaker's emotional state through a trained emotion recognition model. It is designed to provide an intuitive and efficient platform for real-time speech emotion analysis.

The project consists of a Flask-based backend for AI model inference and a modern web interface for user interaction. It supports live speech recording, audio file uploads, real-time emotion prediction, confidence score visualization, prediction history, and Firebase integration for secure data management.

The application is built using Python, Flask, TensorFlow, Librosa, Firebase, HTML, CSS, and JavaScript. Its modular architecture allows for easy scalability and future enhancements, making it suitable for applications in healthcare, education, customer support, and human-computer interaction.

This repository contains the complete source code for both the backend and frontend of the Urdu Emotion AI system developed as part of our Bachelor's Final Year Project in Artificial Intelligence.
